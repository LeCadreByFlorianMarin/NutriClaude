# Revue de code — Epic 1, passe 3/3 : UI & thème

_Date : 2026-07-28 · 33 fichiers, 3460 lignes de diff · état de l'arbre après les passes 1 et 2_

**Périmètre.** `app/globals.css` (66 tokens, deux thèmes, 7 classes de composants), `app/layout.tsx`,
`app/error.tsx`, `app/not-found.tsx`, et les 14 écrans `.tsx`.

**Couches exécutées.** Blind Hunter, Edge Case Hunter, Acceptance Auditor, `/ux-heuristics`,
`/refactoring-ui`, `/tdd` + `/clean-code`. Aucune n'a échoué.

**Note de méthode.** Les ratios de contraste ci-dessous ont été **recalculés indépendamment** des
agents, à partir des tokens du fichier et des arrêts réels du dégradé. Deux couches donnaient des
chiffres légèrement différents ; ceux retenus ici sont les miens.

**Ce qui tient et ne doit pas bouger** — le texte principal est excellent (`--text` à 16,19:1 sur
carte, 14,36:1 sur la page) ; l'anneau de focus est une règle globale sur `:focus-visible`, la bonne
forme ; le plancher tactile `min-h-11` est réellement tenu partout ; les tables `MESSAGES` sont
exemplaires, un message par cause, sans jamais laisser fuiter `error.message` ; la neutralisation
`--color-*: initial` fonctionne (aucune couleur Tailwind par défaut n'est écrivable) ; le thème
sombre tient ses contrastes, halos compris.
